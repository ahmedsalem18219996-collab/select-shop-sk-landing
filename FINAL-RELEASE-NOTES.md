# V15 Guided Motion

V15 keeps the V14 clean-slate visual architecture and changes the interaction model rather than stacking another theme.

Key changes:
- Stronger but purposeful motion system.
- Catalog model selection now opens that model directly in the product selector.
- New sticky 3-step purchase journey: model → size → confirm.
- New live selection summary in the product selector.
- Product selector no longer presents two competing purchase actions.
- `تغيير الموديل` returns to browsing; `تأكيد الاختيار` saves and opens cart review.
- Product/model switches use visible image transitions and clear feedback.
- Mobile carousel emphasizes the card currently in focus.
- Desktop adds lightweight 3D pointer depth and spotlight effects.
- Cart trigger animates when a selection is saved.
- No additional framework or runtime dependency added.
